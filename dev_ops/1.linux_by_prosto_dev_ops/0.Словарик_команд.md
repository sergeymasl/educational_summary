# Commands

## Кто мы, где мы, что это

- `whoami` - отображает под каким юзером сейчас сидит пользователь
- `hostname` - имя сервера
- `pwd` - в какой папке вы сейчас
- `which <command>` - показывает расположение комманды (программы) на диске
- `type <command>` - показывает тип команды (встроенная или отдельная программа)
- `date` - время на сервере в UTC.
- `history` - просмотр введенных команд
- `man <command>` - мануал по команде
- `tldr` - показывает пять-десять самых частых примеров для команды, быстрее чем работать с `man`

## Состояние сервера

- `uname` - вывод версии ядра линукс
- `uptime` - возвращяет, "<**текущую дату**> up <**сколько сервер работает**>, <**сколько юзеров подключено**>, load average: <**средняя нагрузка за 1 минуту**>, <**средняя нагрузка за 5 минут**>, <**средняя нагрузка за 15 минут**>" например `10:15:02 up 12 days, 3:04, 1 user, load average: 0.15, 0.10, 0.09`
- `nproc` - количество ядер у процессора

## Файловая система

- `du -sh <path>` - (disk usage) позволяет просмотреть занимаемое место на диске внутри папки. Удобнее всего использовать с флагами `-s`(показывает результат по папкам, а не по каждому файлу) и `-h`(переводит единицы измерения в человекочитаемый вид)
- `df -h` - (disk free) показывает статистику по дискам целиком, сколько вмего места, сколько занято и сколько свободно
- `find` - поиск файлов по имени/размеру/дате обновления [подробнее](2.Файловая_система.md)
- `mkdir` - создание папки, если мы хотим создать целую иерархию папок, то нужно использовать флаг `-p` (также у этого флага есть свойство, что при уже созданных папках, он не выдаст ошибку, что полезно в скриптах)
- `touch <file_path>` - создаст пустой файл или обновит время модификации если файл уже существует. Флаг `-d` позволит указать свое время для времени модификации файла.
- `cp <from_path> <to_path>` - копирование файла. Команда не копирует папки и если нужна такая необходимость, то устанавливают флаг `-r`, то есть рекурсивно. **При копировании команда изменяет владельца на того кто скопировал и меняет время обновления**, что при миграции на другой сервер не есть хорошо. Однако у команды есть ряд флагов:
  - `-p` - сохраняет владельца, группу, права и время изменения
  - `-a` - копирует папку целиком и сохраняет всё о файлах – как -r и -p вместе
  - `-v` - выводит в консоль файлы которые копирует
  - `-i` - спрашивает, прежде чем перезаписать существующий файл
  - `-n` - никогда не перезаписывает существующие файлы
  - `-u` - копирует, только если исходный файл новее
- `rsync` - сравнивает файлы по размеру и времени изменения и **копирует только то, что поменялось**. Если копирование прервалось, повторный запуск не станет заново копировать уже перенесённые файлы.
- `mv <source> <target>` - перенос файла или его переименование. Для Linux это одно и то же действие – дать файлу новый путь. Если новый путь в другой папке, файл переехал, если в той же – переименовался. Флаг -r для папок mv не нужен: в пределах одного диска папка не копируется, меняется только её адрес, поэтому даже огромная папка переносится мгновенно. Подробнее
- `rm` - удаляение. Самая **опасная** из простых команд. В Linux нет корзины и удалённый файл не вернуть. **Перечисление через пробел, это удаление нескольких файлов**. Поэтому **лишний пробел** – `rm -rf ~ /courier-old` вместо `rm -rf ~/courier-old` – и **команда удалит всю домашнюю папку.**
- `rmdir` - удаление только пустых папок

## Чтение,вывод и фильтрация

- `echo` - вывод в консоль чего либо (аналог print в пайтон)
- `printf` - вывод в консоль, пожжерживающий экранированные символы (/n, /t, etc)
- `cat` - целиком выводит содержание файла. Причем **не только текстовых**, если файл не текстовый то команда выводит набой байтов.
- `head` - выведет начало файла (10 строк по умолчанию, флаг  `-n` позволит указать сколько именно нужно строк)
- `tail` - выведет конец файла (10 строк по умолчанию, флаг `-n` позволит указать сколько именно нужно строк)
  - флаг `-f` позволит команде ***следовать*** за заполнением файла (например когда программа пишет логи прямо во время просмотра). При этом если файл за которым следит команда **будет переименован** например (app.log -> app.log.1) она все равно **продолжит следить за тем файлом который она открыла** то есть за app.log.1
  - флаг `-F` позволяет **следовать** за файлом по имени, то есть при ротации файлов с логами, программа будет следить за файлом который соответсвует названию
- `less` - команда которая читает файл и выдает его **экран за экраном**. Также можно искать по открытому файлу.
  - **Команды уже внутри less:**
  - `space` или `f` - экран вниз
  - `b` - экран вверх
  - `g` - в начало файла
  - `G` - в конец файла
  - `/<слово>` - искать <слово> впереди
  - `?<слово>` - искать <слово> позади
  - `n` или `N` - следующее совпадение или предыдущее
  - `q` - выход
- `wc` - word count, считает сожержимое файлов.
  - `-l` - считает строки (точнее символы перевода строки)
  - `-w` - считает слова
  - `-с` - считает слова
- `grep <шаблон> <путь к файлу|вход из пайпа>` - команда фильтрует и оставляет только строки, в которых есть нужный текст или паттерн. Команда читает и файлы, и **вход из пайпа**
  - `-i` - поиск без учета регистра
  - `-v` - наоборот: строки **без совпадения**
  - `-c` - только число совпавших строк
  - `-n` - номера строк
  - `-l` - только имена файлов, где есть совпадения
  - `-r` - искать во всех файлах папки и вложенных папок
  - `-w` - только целые слова
  - `-o` - печатать не всю строку, а только совпавший кусок
  - `-A 3` - и ещё 3 строки после совпадения (after)
  - `-B 3` - и ещё 3 строки до совпадения (before)
  - `-C 3` - по 3 строки с обеих сторон
  - `-E` - расширенные регулярные выражения
- `sort` - сортирует строки (по умолчанию по алфавиту)
  - `-n` - сортировка по числу
  - `-r` - в обратном порядке
  - `-u` - показывать только уникальные значения
  - `-k <n>` - по n-ому полю строки (поля разделяются по умолчанию пробелами)
  - `-t <sep>` - указание какой именно разделитель у полей
  - `-V` - сортировка по номерам версий
  - `-h` - команда начинает понимать размер в строке (если он есть в stdin) и сортирует по нему (14M, 4.0K, etc)
- `uniq` - убирает дубликаты если **они идут подряд**. Только подряд – поэтому **перед ним почти всегда идёт sort**.
  - `-c` - выводит число повторов строки
  - `-d` - оставляет только строки у которых есть повторы
  - `-u` - оставляет только строки у которых нет повторов
- `tee <file_path>` - отправляет вывод и в файл(как при `>`) и на экран
  - `-a` - дописывает в файл как при `>>`
- `xargs` - превращает свой stdin в аргументы для другой команды. [Подробнее](3.Потоки.md)
- `diff <path> <path>` - сравнивает построчно разницу между двумя файлами
- `cut` - команда позволяет извлечь фрагмент из текстовых данных на основе разделителя
  - `-d` - (delimetr) разделитель
  - `-f` - (field) номер поля который нужен

## Архивирование и сжатие

- `tag` - от Tape Archive. складывает дерево папок и файлов **в один файл** и запоминает структуру, права, владельцев и время изменения каждого файла. Команда **не сжимает файлы**, а только собирирает их в один файл. [Подробнее](4.Архивы_сжатие_передача_файлов.md)
- `gzip` - сжимает файл
- `gunzip` - распаковка из gzip-а
- `tar czf` - упаковка в архив и одновременное сжатие через gzip [Подробнее](4.Архивы_сжатие_передача_файлов.md)
