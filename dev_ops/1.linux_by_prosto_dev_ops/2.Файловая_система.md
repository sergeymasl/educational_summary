# Файловая система

Если в виндовс файловая система строиться на дисках (`C:`, `D:`, etc), то в UNIX подобных системах все файлы и папки собраны в одно дерево.

> Стоит отметить что в UNIX системы придерживаются концепции,что **любая сущность есть файл**: настройки, сведения о процессоре, диски и даже «пустота»

![alt text](./pictures/all_is_file.png)

Практически все UNIX подобные системы, придерживаются стандарта FHS (Filesystem Hierarchy Standard), который определяет назначение папок.

![alt text](./pictures/unix_folders_system.png)

- `/` - корень, начало всех начал. Права писать в корень есть только у суперюзера (он же root)
- `/etc` - файлы с настройками систем и программ. (название исторически сложилось, т.к. изначально сюда скидывали все что не подходит под другие папки)
- `/var` - тут лежат данные которые постоянно изменяеются (variable - переменные): логи, базы данных и т.п.
- `/var/logs` - логи. **Чаще всего иммено здесь кончается место**
- `/home` - директория для папок пользователей, например `/home/maslovso` (он же `~`)
- `/root` - домашняя папка суперпользователя, сознательно отделена от папки `/home`
- `/opt` - стороннее программное обеспечение и пакеты, не входящие в стандартную поставку системы
- `/tmp` - папка для временного хранения. **Отчищается при перезапуске системы** (но зависит от системы)
- `/usr/bin` - хранят пользовательские команды (`ls`, `whoami`, etc). Раньше было разделение на `/bin`(команды без которых системв бы не запустилась) и `/usr/bin`(все остальное), но на современных системах разницы нет. Сейчас используется UsrMerge (объединение папок)  папка `/bin`, отсылает к папке `/usr/bin`
- `/dev` - от слова **device**, специальные файлы, которые выступают в роли интерфейса между аппаратным обеспечением и программным обеспечением.
  - `/dev/null`, псевдоустройство, которое принимает любой ввод и ничего не хранит (можно отправлять файлы которые не нужно хранить)
  - `/dev/zero` - выдаёт нулевые байты без конца
  - `/dev/urandom` - выдаёт случайные байты без конца
- `/proc`, `/sys` — это виртуальная файловая система, предоставляющая интерфейс к внутренним структурам ядра

## Информация о файлах

Информацию о файлах можно получит с помощью команды `ls -l`, которая выведет список файлов в рабочей директории в виде списка, у каждого файла будет собственная строка вида
![alt text](./pictures/file_info_in_list.png)

Тип может быть: `-` - файл или `d` - директория

Флаги, которые могут пригодиться для команды `ls`:

`-a` – показать и скрытые файлы: в Linux скрыты те, чьё имя начинается с точки, например .bashrc;  
`-h` – размеры в понятном виде: 4.0K, 1.2M, 3.8G;  
`-t` – сначала самые свежие;  
`-S` – сначала самые большие;  
`-r` – обратный порядок

---
Также можно отобразить иерархию файлов и папок с помощью команды `tree`

Флаги:
`-L2` – не глубже двух уровней: на больших папках без этого ответ займёт тысячи строк;  
`-d` – только папки;  
`-a` – вместе со скрытыми файлами  

### Find

Для поиска файлов используется команда `find`, которая имеет очень мощный функионал для поиска, например

Синтаксис команды:
`finf <path_for_looking> [parametrs]`

Например

```bash
find /etc -name "*.conf"      # имя по маске: всё, что кончается на .conf
find /var/log -type f         # только файлы
find /var/log -type d         # только папки
find /var/log -size +100M     # больше 100 мегабайт
find /var/log -mtime -1       # дата модификации меньше суток
find /var/log -mtime +30      # дата модификации больше 30 суток
find /home -user student      # принадлежат пользователю student
find -print0 # выводит имя файла, за которым сразу следует нулевой символ (ASCII 0)
```

> Если условий несколько, `find` ищет файлы, которые подходят под все сразу.

Также у команды есть флаг `-exec` который позволяет выполнить какую то команду со **всеми найденными файлами**

Есть два формата:

- `find <find condition> -exec <command> {} \;`
- `find <find condition> -exec <command> {} +`
Где вместо `{}` команда подставляет путь до найденног файла, а символы `\;` и `+` будут определять как запускать пользовательскую команду: для каждого файла или собирает имена в одну команду.

## Информация о занимаемом месте

- `du -sh <path>` - (disk usage) позволяет просмотреть занимаемое место на диске внутри папки.  
Удобнее всего использовать с флагами `-s`(показывает результат по папкам, а не по каждому файлу) и `-h`(переводит единицы измерения в человекочитаемый вид)
- `df -h` - (disk free) показывает статистику по дискам целиком, сколько вмего места, сколько занято и сколько свободно

## Перемещение файлов

> Команды `cp` и `mv` молча перезаписывают файл, если на новом месте уже лежит файл с таким же именем. Старое содержимое пропадёт так же безвозвратно, как после rm. Если не уверены, добавьте флаг `-i` – команда спросит, прежде чем перезаписать.

В пределах одного диска `mv` срабатывает атомарно – целиком или никак. В любой момент по новому пути лежит **либо старый файл полностью, либо новый полностью, промежуточного состояния нет**.
А также мгновенно, т.к. в пределах одного диска `mv` н**е трогает содержимое: он только меняет запись о том, где лежит папка**

Если файл переносится на другой диск, mv работает иначе: сначала копирует, потом удаляет исходный файл. Пока идёт копирование, файл есть в двух местах, и если в этот момент что-то сломается, может остаться половина копии.

![alt text](./pictures/file_mv_logic.png)

Т.к. команда `mv` внутри одной папки работает **атомарно**, и то ч**то она подменяет файл, если такой существует**, то это свойство удобно использовать при обновлении/изменении файлов которые использует программа в работе (файлы настроек, конфигураций и т.д.), сначала копируют файл в той же папке, изменяют копию и **мгновенно и атомарно** командой `mv` подменяют старый файл на новый

![alt text](./pictures/change_file_live_hack.png)

## Маски (или glob)

Маски это некие паттерны в linux которые позволяют работать не с точным названием, а с диапазоном названий:

|Маска|Что значит|Пример|Примечание|
|---|---|---|---|
|*|сколько угодно любых символов|*.log|Звёздочка не находит файлы, имя которых начинается с точки (то есть скрытые)|
|?|ровно один любой символ|report-?.txt||
|[abc]|один символ из перечисленных|report-[12].txt||
|[a-z]|один символ из диапазона|[a-z]*.conf||
|[!abc]|один любой символ, кроме перечисленных|[!.]*||

![alt text](./pictures/mask_logic.png)

Главное – кто работает с маской. **Её раскрывает bash**, **до запуска команды**, так же как фигурные скобки. Команда получает уже готовый список файлов

# Удаление

Удаление **БЕЗОПАСНО**, **когда**:

- сначала применяется маска с `ls` вместо `rm` и она показала ровно те файлы, которые вы хотите удалить;
- путь написан полностью и без лишних пробелов;
- у важных файлов есть копия, сделанная `cp -a`;
- `hostname` и `pwd` подтвердили, что вы на нужном сервере и в нужной папке.
